PART 2 - UNDERSTAND THE FOUR BASIC IDEAS
========================================

WHAT IS LINUX?

Linux is an open-source operating system family.
An operating system helps manage hardware, memory, files, programs and users.
Linux is used on servers, cloud systems, supercomputers, embedded devices,
security workstations and normal desktop computers.

WHAT IS THE KERNEL?

The kernel is the operating system core. It communicates with hardware and
manages resources such as memory, processes and devices.

WHAT IS A DISTRIBUTION?

A distribution, often shortened to distro, is a complete Linux system built
from the Linux kernel and a collection of tools and software.
Examples include Debian, Ubuntu, Fedora and Kali Linux.

WHAT IS A TERMINAL?

The terminal is an application window where you type commands and read output.

WHAT IS A SHELL?

The shell runs inside the terminal. It reads commands and asks the operating
system to perform them. Bash and Zsh are common shells.

Memory sentence:
The terminal is the window; the shell interprets the commands inside it.

PART 4 - UNDERSTAND THE TRAINING VM
===================================

The interface resembles a Linux security-training desktop.

Top panel:

- Applications opens the training application menu.
- LINUX BASICS TRAINING VM identifies the fictional machine.
- The right side shows language, status and local time.

Left dock:

- Terminal opens the 50 command missions.
- Review opens the final questions.
- Flag opens the final practical challenge.
- Guide downloads this walkthrough.

Mission panel:

- Shows all 50 missions.
- The current mission is highlighted.
- Completed missions receive a tick.
- Later missions stay locked until earlier commands are completed.

Instruction card:

- Explains the command before you run it.
- Explains why you are learning it.
- Shows the exact task and exact command.
- Provides a beginner hint.
- Contains Previous mission and Next mission buttons.

Terminal window:

- The black area displays commands and output.
- The bottom line is where you type.
- The prompt looks similar to:

  student@linux-lab:~$

- student is the fictional username.
- linux-lab is the fictional hostname.
- ~ represents /home/student, the student's home directory.
- $ marks the location where a normal user types a command.


HOW TO COMPLETE EVERY COMMAND MISSION
=====================================

Repeat this process for all 50 missions:

1. Read the mission title.
2. Read the command description.
3. Read "Why you are using it."
4. Read "Your exact task."
5. Click inside the black terminal input at the bottom.
6. Type the exact command shown in the instruction card.
7. Press the Enter key or click the blue Run button.
8. Read the command output.
9. Read the green status message below the terminal.
10. Click "Next mission."

If typing is difficult:

1. Click "Copy command."
2. Click inside the terminal input.
3. Paste the copied command.
4. Press Enter.

Linux is case-sensitive.
Documents and documents are not the same name.
Quotes, spaces, hyphens, dots and slashes matter.

FINAL LEARNING CHECKLIST
========================

After completing the lab, you should be able to explain:

1. Linux is an open-source operating system family.
2. The kernel is the operating-system core.
3. A distribution combines Linux with tools and software.
4. A terminal is a window and a shell interprets commands.
5. whoami displays the current user.
6. pwd displays the current location.
7. ls lists content and ls -la includes details and hidden names.
8. cd changes location and cd ~ returns home.
9. mkdir creates a directory and touch can create an empty file.
10. cat displays text-file content.
11. cp copies and mv moves or renames.
12. rm removes files and must be used carefully.
13. head and tail inspect the beginning and ending of files.
14. grep filters matching lines and find searches directory trees.
15. chmod changes permissions.
16. df checks storage, free checks memory and ps shows processes.
17. man provides local command documentation.
18. Commands should be read, understood and verified before use.
