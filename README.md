# Linux Launchpad - Beginner Linux Lab

This is a dependency-free, GitHub Pages-compatible Linux basics lab. It includes a simulated Kali-style training desktop, 50 guided commands, a final quiz, a flag hunt and a downloadable certificate.

## Required website files

- `index.html`
- `styles.css`
- `app.js`

Keep these three files together. Open `index.html` directly or publish the folder with GitHub Pages.

## Student walkthrough

- `LINUX-LAB-COMPLETE-CLICK-BY-CLICK-WALKTHROUGH.txt`

The walkthrough contains every click, exact command, expected output, final answer and troubleshooting step.

## Technical notes

- No packages, server or build process are required.
- No commands run on the learner's real computer.
- Progress is stored in browser local storage.
- The certificate is generated locally as a PNG.
