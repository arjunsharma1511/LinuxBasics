Orientation

What is Linux?

Linux is an open-source operating system family. An operating system manages a computer’s hardware, files, memory, programs and user interactions. Linux is used on servers, cloud platforms, supercomputers, embedded devices, security workstations and everyday computers.

01

Kernel

The core that communicates with hardware and manages resources such as memory, processes and devices.

02

Distribution

A complete Linux system built from the kernel plus tools and software. Examples include Debian, Ubuntu, Fedora and Kali Linux.

03

Shell

A program that reads commands and asks the operating system to perform them. Bash and Zsh are common shells.

04

Terminal

The application window where you type commands and read their output. The terminal hosts a shell session.

A useful distinction: the terminal is the window; the shell is the command interpreter running inside it. This lab simulates both in your browser, so no real files or system settings are changed.

Why learn the command line?

Precise

A command clearly states the operation you want.

Repeatable

The same command can be documented and used again.

Remote-friendly

Many servers are managed through text-based sessions.

Observable

Commands and their output provide useful evidence.

Safe learning boundaries

  • Type only the commands shown by the current mission.
  • Read a command’s description before running it.
  • Linux is case-sensitive: Documents and documents are different names.
  • Spaces, quotes, hyphens and capital letters matter.
  • This simulator is fictional and cannot change your real computer.

Scenario

Your instructor stored three harmless flag fragments inside the fictional ~/challenge directory. Use navigation, hidden-file listing, reading, filtering and finding commands to recover them. Join the fragments with no spaces.

  1. Move into the challenge:cd ~/challenge
  2. Reveal hidden names:ls -la
  3. Read the instructions:cat README.txt
  4. Read the hidden first fragment:cat .flag-part1
  5. Filter the log for the second fragment:grep "FLAG_PART" logs/system.log
  6. Find the third fragment:find . -name "part3.txt"
  7. Read the file returned by find:cat archive/part3.txt
